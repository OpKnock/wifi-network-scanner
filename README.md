# WiFi Network Scanner

Passive 802.11 beacon/probe analysis toolkit (pure offline logic): parses beacon frames, extracts SSID/BSSID/channel/security, and classifies networks. Educational only - no radio access required.

## Educational Purpose

**Important:** This tool is intended solely for educational and authorized network security research purposes. WiFi network analysis is a fundamental skill in understanding wireless security. This tool should only be used on networks you own or have explicit written permission to analyze.

### Authorized Use Only

- Only analyze WiFi networks on networks you own or administer
- Obtain explicit written permission before analyzing any WiFi environment
- Report any discovered security findings to the appropriate network owners
- Never analyze WiFi networks you do not have explicit authorization for

### Educational Value

Understanding WiFi network methodology helps network security professionals:
- Identify and classify wireless networks
- Design proper network monitoring and detection systems
- Implement effective WiFi security measures
- Build more secure wireless network architectures

### Legal Compliance

- Unauthorized analysis of WiFi networks may violate Computer Fraud and Abuse Act (CFAA)
- Wireless regulatory laws and applicable regional regulations
- Always obtain explicit written permission before analyzing any WiFi environment

### Responsible Use

- This project is provided for educational purposes only
- Results should be verified with proper security tools for real-world use
- Never use discovered techniques for unauthorized network mapping
